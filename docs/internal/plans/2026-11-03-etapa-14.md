# Plano — Etapa 14: editor de molduras

Prompt aprovado: `docs/internal/spec/ETAPA_14_EDITOR_DE_MOLDURAS.md`. Base `98d57af`,
466 Rust + 15 PowerShell.

## Decisões

- **Imagens no Core** (`domain/asset.rs`): `AssetId` (UUID v7) e
  `ImageAsset` (tipo PNG/JPEG, largura/altura em px, bytes). O Core lê só o
  cabeçalho (assinatura, dimensões, limites 10 MB / 4096 px) sem dependência
  de decodificação; a GUI decodifica com `image` para validar o conteúdo e
  criar a textura. Imagens iguais (mesmos bytes) são reaproveitadas.
- Bytes das imagens não vão para `project.json`: o `.cadcraft` grava
  `assets/<id>.png|jpg`; o snapshot técnico JSON leva só os metadados (a GUI
  desenha um marcador de imagem ausente).
- `FrameElement::Image { rect, asset }` e `FrameTextStyle.watermark`
  (desenhado antes do conteúdo, cor clara).
- `FrameTemplate::draft()`/`edited(FrameDraft)` (mesmo ID, versão + 1),
  `duplicate(nome)` (novo ID, versão 1).
- `FrameEdit::AddAsset`, `RemoveAsset` (sem uso), `Batch` com reversão.
- `.cadframe` (Core, `persistence`): ZIP com `mimetype`, `manifest.json`
  (`kind: frame`, `format`, `min_reader`), `frame.json` e as imagens; mesmo
  leitor defensivo. `Project::frame_import_edits(pacote)` remapeia IDs
  (moldura nova se o ID já existir, imagens reaproveitadas por conteúdo).
- `.cadcraft` formato 3 / `min_reader` 3, migração 2→3 identidade, fixture v3.
- **GUI**: modo editor de moldura ocupando a área de documentos (aba
  "Moldura: nome"), ferramentas selecionar/linha/retângulo/círculo/arco/
  texto/texto especial/imagem, mover/duplicar/excluir/alinhar à grade,
  propriedades do elemento e da moldura no painel lateral do editor, comandos
  na guia Dados-mestre (nova, abrir, duplicar, excluir, exportar, importar),
  pasta de biblioteca nas preferências, texturas em cache por `AssetId`.
  Cada edição confirmada é um `UpsertFrame` (versão + 1) no histórico comum.
