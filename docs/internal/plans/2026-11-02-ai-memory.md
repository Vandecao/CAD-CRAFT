# Instalação operacional do ai-memory — 2026-11-02

Autorização: pedido expresso do usuário para instalar e ativar
`akitaonrails/ai-memory`. Esta intervenção é ambiental e não altera o escopo
funcional da Etapa 9.

1. Conferir AGENTS, memória de retomada, estado Git somente por consultas e
   documentação oficial de instalação nativa do Windows/Codex.
2. Verificar o instalador pela soma SHA-256 publicada; instalar o binário sem
   clonar repositório nem modificar o Git do CAD-CRAFT.
3. Aplicar `setup --yes --agent codex`, conferir serviço, MCP, hooks e skills.
4. Confiar nos hooks após inspecionar os comandos, disponibilizar a credencial
   ao Codex e testar uma sessão curta sem alteração de arquivos.
5. Registrar evidências, limites e estado de retomada; validar o workspace e
   informar que todo commit/push do CAD-CRAFT é manual.

Não executar `ai-memory bootstrap` nem importar histórico da Etapa 9 nesta
intervenção. A memória automática começa nas sessões futuras do Codex.
