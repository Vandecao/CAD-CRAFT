## Desenho técnico
- `interchange/edz/mod.rs`: API `import(bytes: &[u8]) -> ImportResult<EdzImport>`; `EdzImport { container: EdzContainer, parts: Vec<Part>, macros: Vec<MacroDefinition>, report: ImportReport, unknown_codes: BTreeSet<String> }`. `EdzContainer::{Zip, SevenZ}`. Ligações peça/macro em propriedades técnicas `P_ARTICLE_*MACRO` originais e `CADCRAFT.MacroIds` (IDs convertidos pelo manifesto).
- `archive.rs`: limites antes e durante leitura, normalização segura de caminhos, duplicatas recusadas, nunca extrair em disco.
- `parts.rs`: XML de peças/fabricantes/pontos, preservação de atributos originais, preferência pt-BR/en-US, funções sem adivinhação de códigos.
- `pxf.rs`: biblioteca embutida, primitivas, ocorrências/portas/ligações/textos. Construir projeto temporário e capturar macro pelas APIs existentes. Tabela de códigos no ADR-0028, observada das amostras.
- `cad-gui/src/edz_import_ui.rs`: lotes de arquivos ou pasta, análise/progresso/cancelamento, prévia por pacote, confirmação com conflitos substituir/manter ambas/pular, recarga das bibliotecas. Testes egui/accesskit sem executável.
- Testes sintéticos ZIP/7z, limites, XML inválido, item ausente, fallback, persistência e inserção/undo. Teste opcional por `CAD_CRAFT_EDZ_SAMPLES` gera cobertura só com contagens e códigos.
