# Especificações

`PROMPT_0.md` preserva a solicitação original do bootstrap.
A instrução posterior do usuário prevalece: utilizar o origin existente;
não criar outro repositório nem configurar nova conexão GitHub.
Guardar aqui os prompts das Etapas 1 a 15 à medida que forem recebidos.

`POLITICA_GIT_GITHUB_BACKUP.md` preserva integralmente a instrução complementar
de 2026-10-26. Ela substitui as regras operacionais incompatíveis do Prompt 0:
versionamento e sincronização são exclusivamente manuais. Não autoriza Etapa 1.

`ETAPA_01_CORE_DOMINIO.md` preserva integralmente o anexo recebido em 2026-10-26,
que autoriza a Etapa 1 e mantém o controle manual do Git.

`ETAPA_02_CONECTIVIDADE_REDES.md` preserva integralmente o anexo recebido em
2026-10-27, autorizando execução autônoma da Etapa 2 e revisão independente,
mantendo a política Git manual. Esse anexo não autoriza etapas posteriores.

`ETAPA_03_CONDUTORES_CABOS_BORNES.md` preserva integralmente o anexo recebido em
2026-10-27, autorizando implementação, testes e revisão independente da Etapa 3.
Commit manual após esta etapa; push manual após a Etapa 4. Etapa 4 não autorizada.
