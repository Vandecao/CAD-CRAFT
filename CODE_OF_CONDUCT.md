# Code of Conduct

CAD-CRAFT adopts the **Contributor Covenant, version 2.1**, as its code of conduct for everyone who takes part in the project: issues, pull requests, discussions and any other project space.

The full text is available at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and welcoming, accept constructive criticism, focus on what is best for the community, and do not harass, insult or publish others' private information.

## Reporting

Report unacceptable behavior privately to the project maintainer through the contact options on the maintainer's GitHub profile. Reports are handled confidentially.
