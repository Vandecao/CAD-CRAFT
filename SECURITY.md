# Security Policy

CAD-CRAFT opens files produced by other programs (QElectroTech, EPLAN, DXF and others). A file that makes the program crash, hang, use excessive memory, or read or write outside the expected place is a security problem.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting: on the repository page, open **Security** → **Report a vulnerability**. Include:

- the CAD-CRAFT version or commit;
- the file type and, if possible, a minimal file that reproduces the problem, without proprietary content;
- what happens and what you expected.

You will receive an answer as soon as possible. Fixes are published in a new release, and the reporter is credited unless they prefer otherwise.

## Supported versions

CAD-CRAFT is in alpha. Only the latest commit on the `main` branch receives security fixes.
